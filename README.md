# 🏎 Turbo Crew — гонки с друзьями онлайн

Мультиплеерные гонки в браузере (ПК и телефон), до 8 игроков в комнате.

## Режимы
- 🏁 **Классика** — 2/3/5/8 кругов, кто первым финишировал. Машины сталкиваются.
- ⏱ **Лучший круг** — 90 секунд, побеждает самый быстрый круг. Без столкновений.
- 💥 **Выбывание** — каждые 15 секунд (после первых 20) вылетает последний.
- 🥊 **Сумо-арена** — выталкивай соперников за край, арена сужается.

## Управление
- ПК: **WASD / стрелки**, **Пробел** — турбо (перезарядка 4 с).
- Телефон: кнопки на экране (◀ ▶ руль, ▲ газ, ▼ тормоз, 🚀 турбо).
- Камера: кнопка справа под мини-картой или клавиша **C** — 📷 3-е лицо → 👁 1-е лицо (из кабины) → 🗺 вид сверху. Выбор запоминается.

## Запуск
```bash
npm install
npm start
```
Открой http://localhost:3000, нажми «Создать комнату» и отправь друзьям код (или кнопку «Позвать друзей» — это ссылка с кодом).

## Играть с друзьями через интернет
1. **Быстро, с твоего компьютера** — пока сервер запущен, открой туннель:
   `npx cloudflared tunnel --url http://localhost:3000` (или ngrok) и отправь друзьям выданную ссылку.
2. **Постоянно** — залей папку на любой хостинг с Node.js и поддержкой WebSocket (Render, Railway, Fly.io и т. п.). Команда запуска: `npm start`, порт берётся из переменной `PORT`.
3. **В одной Wi-Fi сети** — друзья заходят на `http://<IP-твоего-компьютера>:3000`.

## Как устроено
- `server.js` — комнаты, лобби, логика режимов, результаты (WebSocket, библиотека `ws`).
- `index.html` — вся игра: трасса, физика, интерфейс, управление.
- Каждый клиент считает физику своей машины и шлёт позицию 20 раз в секунду; сервер раздаёт позиции всем и судит заезд. Для игры с друзьями этого достаточно (защиты от читеров нет).
